# HTML-страница "О себе"
Тема: "Эко-активист"
# Цель проекта
Освоить базовую структуру HTML-документа, теги, списки, формы, изображения, стили CSS, а также основы JavaScript.
# Реализация
В HTML-документе были использованы следующие компоненты:
  • Блоки header, main, section, aside, footer;
  • Разделы "Навыки" и "Проекты" с применением маркированного и нумерованного списков;
  • Изображение с атрибутами src, alt, width, height;
  • Форма обратной связи с полями для ввода имени, электронной почты и сообщения;
# Оформление проекта
Для оформления HTML-документа была использована зелёно-белая цветовая гамма.
# Технологии
HTML5, CSS3, JavaScript
