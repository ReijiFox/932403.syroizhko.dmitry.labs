# Эко-активист

## Описание проекта

«Эко-активист» — это персональная веб-страница, посвящённая экологичному образу жизни. Сайт содержит информацию об экопривычках, городских экологических инициативах и способах сделать повседневную жизнь более экологичной.

Проект разработан в рамках лабораторных работ по веб-программированию с использованием HTML, CSS и JavaScript.

## Используемые технологии

**HTML5**
**CSS3**
**JavaScript**
**DOM**
**localStorage**

## Возможности сайта

- Просмотр информации об экологичном образе жизни.
- Ознакомление с экопривычками и городскими инициативами.
- Добавление новых экопривычек.
- Отслеживание прогресса выполнения привычек.
- Увеличение прогресса с помощью кнопки «Отметить».
- Сброс прогресса всех привычек.
- Скрытие и отображение карточек привычек.
- Переключение между светлой и тёмной темами оформления.
- Автоматическое сохранение данных в localStorage.
- Восстановление сохранённых данных после повторного открытия страницы.

## Сохранение данных

Сайт использует браузерное хранилище localStorage. Добавленные привычки, их прогресс и выбранная тема оформления сохраняются автоматически.
Сохранённые данные привязаны к конкретному браузеру и устройству. При открытии сайта в другом браузере они не переносятся.

## Цель проекта

Основная цель проекта — закрепить практические навыки создания веб-страниц, работы с HTML и CSS, использования JavaScript для взаимодействия с DOM, а также освоить сохранение пользовательских данных в браузере.
