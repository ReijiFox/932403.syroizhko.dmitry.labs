# Тема

Эко-активист. Aнализ потребления воды за неделю.

# Цель работы

Изучить работу с массивами, функциями, условными конструкциями и циклами в JavaScript.

# Описание программы

Программа анализирует потребление воды за 7 дней: она вычисляет общее и максимальное потребление, определяет дни, когда потребление превысило 3 литра, подсчитывает количество и процент дней с потреблением не более 1,5 литра, рассчитывает среднее потребление за неделю.

Если среднее потребление составляет менее 2 литров в день, программа выводит рекомендацию увеличить потребление воды до 2–2,5 литров в день.

# Примеры работы

input.png — ввод имени пользователя.

greeting.png - приветствие пользователя с введённым именем.

total.png - вывод на экран информации о количестве потребления воды за неделю и количестве дней, когда норма была превышена.

calcs.png — результаты вычислений в консоли браузера.

debug.png — проверка программы после изменения значений массива.

# Использованные средства

HTML5, CSS3, JavaScript, браузер и инструменты разработчика.

# Результат

Создана программа для анализа потребления воды за неделю. Проверена корректность вычислений при изменении исходных данных.
