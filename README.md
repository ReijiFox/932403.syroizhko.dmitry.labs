**Эко-активист**
Веб-приложение "Эко-активист" в рамках лабораторной работы №6. 
Проект представляет собой сайт для формирования эко-привычек.

**Цель**
Расширить существующее веб-приложение, добавив серверную часть и реализовать возможность работы в формате PWA.
В рамках лабораторной работы требуется:
  1. Создать сервер на Node.js с использованием готовой библиотеки Express.
  2. Реализовать GET-маршруты для главной страницы и страницы "О себе".
  3. Организовать раздачу статических файлов приложения.
  4. Разработать API для конвертации валют с использованием query-параметров.
  5. Реализовать проверки данных и обработку ошибок.
  6. Создать манифест PWA с описанием приложения и его иконками.
  7. Создать service worker для обеспечения кеширования данных приложения и его работы в режиме "оффлайн".
  8. Проверить возможность установки PWA через браузер.

**Технологии**
HTML5, CSS3, JavaScript, Node.js, Express, npm, JSON, Web App Manifest, Service Worker.


**Реализация**
С помощью Node.js и Express создан сервер с портом 3000.
Реализованы маршруты: /, /about, /api/convert.
С помощью express.static() обеспечивается доступ к HTML-, CSS- и JavaScript-файлам, изображениям и иным ресурсам приложения.

Реализован маршрут /api/convert, который принимает query-параметры from, to и amount для получения данных об исходной валюте, целевой валюте и о количестве исходной соответственно.
Доступные курсы: USD -> EUR, USD -> RUB, EUR -> RUB.
API проверяет, что обе валюты существуют в списке валют, что сумма является положительной и что курс для выбранного направления конвертации существует.
При успешном выполнении запроса сервер возвращает в формате json параметры: from, to, amount, result (результат конвертации) и rate (значение курса).

Для преобразования сайта в PWA были созданы манифест, содержащий общую информацию о приложении, и service worker, обеспечивающий кеширование необходимых HTML-,
CSS- и JavaScript-файлов, манифеста и изображений, перехват сетевых запросов, удаление старых кешей при появлении новых версий, а также получение ресурсов из кеша при отсутствии подключения к интернету.

Реализована возможность открытия главной страницы и страницы "О себе" без подключения к интернету при условии, что необходимые ресурсы предварительно находятся в кеше.
Обеспечена возможность установки приложения через браузер.
